# AVP Governance — Alpha

AVP is currently an experimental proposed open protocol.

## Alpha governance

- Maintainers approve releases and normative changes.
- All normative changes are public PRs/AEPs.
- Conformance requirements and tests are public.
- Stable core semantics must not depend on a proprietary service.

## Planned maturity path

```text
Experimental
→ Candidate
→ Stable 1.0
→ Multi-vendor governance
```

Before AVP 1.0, the project should have at least two independent AVP-Core implementations and public TCK coverage for all Core MUST requirements.
