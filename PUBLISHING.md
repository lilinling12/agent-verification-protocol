# Publishing to GitHub

Target repository recommendation:

```text
lilinling12/agent-verification-protocol
```

Recommended visibility: **public**, because the project is intentionally designed as an open protocol/specification with a public TCK.

Repository creation is not available through the currently connected GitHub App action set in this session, and `gh` is not installed in the execution environment.

Once the empty repository exists, the repository tree in this package can be published as the initial Alpha commit. No README/LICENSE initialization is required on GitHub because both are already included here.

Suggested first commit:

```text
bootstrap AVP alpha reference implementation
```

Suggested initial release/tag after CI passes:

```text
v0.1.0-alpha.1
```
