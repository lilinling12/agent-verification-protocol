## Protocol and conformance impact

Stable `v0.3.0` promotes the already-closed and already-Final Alpha 2 normative surface to the stable conformance baseline. It does not introduce new normative semantics relative to the accepted Alpha 2 surface.

The authority order remains:

1. normative specification;
2. requirement indexes and accepted governing AEPs;
3. schemas and language-neutral TCK;
4. reference implementation.

AEP-0001 through AEP-0008 are `Final`. The reference implementation remains downstream of the protocol and TCK and does not reverse-define normative expectations.

## Compatibility

The stable package version is exact `0.3.0`. Consumers may use tag `v0.3.0` as the stable Alpha 2 conformance target and should continue to validate behavior against the registered Alpha 2 TCK profiles.

No incompatible normative migration was intentionally introduced by the stable selection itself. Reference-runtime users moving from RC1 should review the RC2 notes for post-RC1 implementation-identity and evidence-quality corrections.

## Security review

The stable release does not weaken existing fail-closed or authority boundaries, including:

- Subject/Evaluator separation;
- protected evaluator material handling;
- Oracle verdict and execution-failure separation;
- immutable Artifact/Evidence integrity checks;
- Artifact Trust claim-honesty requirements;
