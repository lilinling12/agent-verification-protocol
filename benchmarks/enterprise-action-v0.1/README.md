# AVP Enterprise Action Benchmark v0.1

This is an **AVS design pack**, not yet a scored public leaderboard.

It targets action-taking enterprise agents across six capability families: Commerce, Calendar, Email, Files, Approval, and MCP Orchestration.

Each family emphasizes State, authority, control decisions, faults, and collateral effects rather than natural-language style alone.

## Tracks

- clean
- ambiguity/control
- chaos/recovery
- security
- repeated reliability

Public templates are examples; serious benchmark scoring should use private/generated ScenarioInstances to reduce contamination and overfitting.
