# AVP / AVS Benchmarks

`benchmarks/` contains capability and reliability evaluation packs built on AVP. Benchmarks are not protocol conformance tests.

- Conformance asks whether an implementation satisfies AVP semantics.
- Benchmarking asks how reliably/capably an Agent System performs a task distribution.

Benchmark packs may evolve faster than the protocol and may include domain-specific tasks, generators, scoring policies, and datasets. They must not become normative AVP semantics by convention.

Public AVS packs can live here during Alpha. Enterprise/private packs and production-mined datasets may remain outside this repository.
